# dotfiles

Hyprland rice with dynamic Material You theming via matugen + pywal. Managed with GNU Stow.

## what's inside

```
autostart/   -> cliphist autostart
bin/         -> walset (theme picker), walset-backend, togglebar, helper scripts
eww/         -> fullscreen sysinfo overlay (CPU, mem, temp, network, workspace)
hypr/        -> hyprland, hyprlock, hypridle, keybindings, window rules
kitty/       -> terminal config + dynamic colors
matugen/     -> Material You color templates for all components
rofi/        -> launcher, clipboard picker, note launcher, theme picker
swaync/      -> notification center
systemd/     -> user services
uwsm/        -> session management
waybar/      -> bar config, weather script, mediaplayer, battery ASCII
xdg/         -> xdg-desktop-portal config
```

## dependencies

**core**

```
hyprland hyprlock hypridle hyprsunset hyprpolkitagent
waybar eww rofi swaync
kitty
```

**theming**

```
matugen python-pywal awww
```

`walset` opens a rofi wallpaper picker, then `walset-backend` runs pywal + matugen to regenerate colors for everything (hyprland, waybar, eww, kitty, rofi, GTK, Qt).

**utilities**

```
cliphist wl-clipboard brightnessctl playerctl
grim slurp jq curl imagemagick
udiskie networkmanager power-profiles-daemon
```

**optional**

```
librewolf thunar nvim pywalfox
```

## install

```bash
git clone https://github.com/ReGHZ/dotfiles.git ~/dotfiles
cd ~/dotfiles
```

Stow everything:

```bash
stow */
```

Or pick specific modules:

```bash
stow hypr waybar kitty rofi eww
```

This symlinks each folder's contents into `$HOME`. For example `stow hypr` creates `~/.config/hypr/ -> ~/dotfiles/hypr/.config/hypr/`.

## first run

After stowing, generate the initial color theme:

```bash
walset
```

This opens a rofi picker to select a wallpaper from `~/Pictures/Wallpapers/`. It then:

1. Sets the wallpaper via awww
2. Generates pywal colors
3. Runs matugen to create Material You colors
4. Regenerates config files: hyprland colors, waybar CSS, eww SCSS, kitty colors, rofi theme
5. Restarts waybar and swaync

Without running this, color config files exist with defaults from the repo — everything works, but colors won't match your wallpaper.

## eww sysinfo

The eww widget is a fullscreen background overlay showing CPU, memory, temps, network, and workspace info. Toggle it with whatever keybind you set (check `hypr/.config/hypr/keybindings.conf`).

## weather

Waybar weather module pulls data from wttr.in (auto-detects location via IP). Cached for 30 minutes. Shows condition + temperature in ASCII format like `[rain] +26°C`, with detailed tooltip on hover (feels-like, humidity, wind, UV).

## notes

- Color files (`colors.conf`, `colors.scss`, `waybar-colors.css`, etc.) are auto-generated by matugen but committed to the repo so everything works out of the box
- `walset-backend` checks if wallpaper is grayscale and uses a monochrome scheme if so
- Hyprlock config is also regenerated on theme change with matching colors
